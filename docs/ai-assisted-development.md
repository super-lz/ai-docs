# AI 辅助开发

用于改进 AI 辅助软件开发流程的项目和工具。

## Leazer Skills

Leazer 维护的 Skills 源码仓库，包括界面清晰度审查、Flutter 多品牌生命周期和 Norn 项目治理等能力。

- https://github.com/super-lz/leazer-skills

## Skills For Designers and Engineers

Emil Kowalski 整理的 UI 设计与动效 Skills，覆盖界面设计、Web 与 React Native 动效、Apple 设计原则、UI 库选择和移动端体验优化。

- https://github.com/emilkowalski/skills

## Find Skills

用于从开放 Agent Skills 生态中发现合适的 Skill，适合查找某类开发能力是否已有可复用方案。

- https://www.skills.sh/vercel-labs/skills/find-skills

## skills_lint

用于 Agent Skills 的静态检查工具，可校验 `SKILL.md`、YAML frontmatter、命名、目录结构和相对路径，适合接入 CI 或 pre-commit。

- https://pub.dev/packages/skills_lint

## 腾讯云 CloudBase

腾讯云提供的 Serverless 应用开发平台，适合为 AI 应用快速接入数据库、对象存储、云函数、托管与鉴权等后端能力。

- https://tcb.cloud.tencent.com/

## 图形与设计协作

可由 Agent 直接生成、读取或持续维护的白板、图表和设计文件。

### Excalidraw MCP

面向 Codex CLI、MCP 和 Agent Skill 的本地 Excalidraw 画布工具，支持持久化目录、命名快照、截图校验与可提交的 `.excalidraw` 文件；适合手绘白板、架构图和流程图。

- https://github.com/yctimlin/mcp_excalidraw

### draw.io MCP

draw.io 官方 MCP 与 Codex CLI 插件，原生生成可提交 Git 的 `.drawio` 文件，也可用于架构图、UML 和系统流程；适合作为稳定的正式图表方案。

- https://github.com/jgraph/drawio-mcp

### Penpot

开源的协作式产品设计平台，官方 MCP 可读写设计文件；以 PostgreSQL、账号、项目与版本管理设计资产，适合 UI/UX 原型和产品界面。

- https://github.com/penpot/penpot
