# AI 辅助开发

用于改进 AI 辅助软件开发流程的项目和工具。

## Leazer Skills

Leazer 维护的 Skills 源码仓库，包括界面清晰度审查、Flutter 多品牌生命周期和 Norn 项目治理等能力。

- https://github.com/super-lz/leazer-skills

## Find Skills

用于从开放 Agent Skills 生态中发现合适的 Skill，适合查找某类开发能力是否已有可复用方案。

- https://www.skills.sh/vercel-labs/skills/find-skills

## skills_lint

用于 Agent Skills 的静态检查工具，可校验 `SKILL.md`、YAML frontmatter、命名、目录结构和相对路径，适合接入 CI 或 pre-commit。

- https://pub.dev/packages/skills_lint
